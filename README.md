# Snapflow

Homepage redesign concept for [snapflow.design](https://www.snapflow.design), by Umar Khalid. Unofficial; facts and copy come from the live site.

- Obsidian lab theme with a white mode toggle
- Scroll-driven story (GSAP ScrollTrigger + Lenis), three.js glass hand and 3D hexagon
- English and Spanish

## Run locally

```bash
npm install
npm run dev
```

Built with Next.js 15, React 19, Tailwind CSS 4, GSAP, Motion and three.js.
